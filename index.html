Metric definitions

Average and maximum waiting time use all scheduled customers, including unfinished ones. Throughput is completed customers divided by the observation window ending at the latest scheduled finish. Utilization counts service seconds only, never waiting, over that same window.

How SmartServe works

A transparent simulation model designed for operational decisions, not a claim of trained AI.

1. Schedule
For each arrival, estimate each counter's availability as the end of its existing workload. Pick the earliest predicted completion; ties go to the lowest counter number.
2. Measure
Waiting time = service start − arrival. Turnaround = finish − arrival. A customer never starts before arrival, even when every counter is idle.
3. Interpret
Customers are sorted by arrival, with token order as a deterministic tie-break. Events are evaluated chronologically, and zero-duration work completes at its start time.
